# Монтажна Сороки — Сорока ТВ 🦅

Інтерактивна навчальна міні-гра для онлайн-уроків у Zoom для дітей 9–10 років:
«Думка 💡 → Бо (Причина) 🔑 → Наприклад 📸» (вкластися у 30 секунд).

---

## 🚀 Як викласти на GitHub Pages (2 простих способи)

### Спосіб 1. Найпростіший (ОДИН автономний файл `index.html`)
Якщо ви не хочете налаштовувати збірки та команди:
1. Візьміть готовий файл `public/montazhna-soroky.html`.
2. Перейменуйте його на `index.html`.
3. Завантажте цей єдиний файл у корінь вашого репозиторію на GitHub (через кнопку **Add file** ➔ **Upload files**).
4. У репозиторії перейдіть у **Settings** ➔ **Pages** ➔ **Source**: `Deploy from a branch` (гілка `main`, папка `/ (root)`).
5. **Готово!** Сторінка запрацює миттєво.

---

### Спосіб 2. Повний проект через GitHub Actions (автоматична збірка)
Усі файли проекту вже повністю налаштовані:
- `vite.config.ts` налаштовано з `base: './'` (працює з будь-якою назвою репозиторію).
- Додано `.github/workflows/deploy.yml` (використовує Node 22 та команду `npm ci --legacy-peer-deps`).
- Створено `package-lock.json`.

**Кроки:**
1. Створіть новий репозиторій на GitHub (наприклад, `montazhna` або `editing`).
2. Запушіть або завантажте всі файли проекту в репозиторій.
3. У репозиторії на GitHub відкрийте **Settings** (Налаштування) ➔ зліва **Pages**.
4. У розділі **Build and deployment** у пункті **Source** виберіть:
   👉 **`GitHub Actions`**
5. GitHub автоматично запустить workflow збірки. За 1 хвилину сайт буде доступний за адресою:
   `https://<ваш-логін>.github.io/<назва-репозиторію>/`

---

## 👥 Два режими гри
1. **Режим дитини (за замовчуванням):** `index.html` — вибір новин, 4-кроковий майстер монтажу, кошик, заміна пастки, перестановка, маркери, суфлер.
2. **Режим викладача для Zoom:** `index.html?mode=teacher` — сітка 12 карток новин для позначки «Зайнято 🔒», щоб діти не обирали однакові сюжети.
